# Trust Boundary Summary

## Public Trust Boundary

The public release is source-backed and verified by:

- public release hash checks
- trust log verification
- public OpenAPI drift checks
- route maturity/profile checks
- public safety gates
- path and secret scans

## Human Review Boundary

The system preserves `review_required` behavior for:

- unsupported future BS assumptions
- payroll or repayment-style workflows
- banking-sensitive workflows
- missing official source evidence
- source conflicts
- private data requirements

## Authority Boundary

Parva is not official authority. It can support verification and machine-readable distribution, but final civil, Panchanga, holiday, fiscal, legal, banking, payroll, tax, and religious decisions remain with the relevant authorities or institutions.
