# Known Limitations

- Public Future-BS behavior is intentionally bounded; unsupported exact official predictions are not exposed.
- JPL/DE440 integration is a foundation and policy layer, not a public official date engine.
- The public benchmark v0 has 38 tasks and is useful for category proof, but it is not a full national conformance suite yet.
- AI-tool and MCP packages are optional adapters; the core system remains the verified public API and SDKs.
- Government and vendor packets are proposal/readiness material, not proof of adoption.
- Ambient local shell defaults may differ from expected toolchains; release tooling resolves Python 3.11 and Node 20 for verification.
