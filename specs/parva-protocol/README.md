# Parva Protocol

Parva Protocol is a public preview specification for programmable, verifiable, auditable Nepali time.

Protocol version: `parva-protocol-0.1.0`

The protocol standardizes how systems represent calendar dates, source evidence, confidence labels, release manifests, evidence packets, TimeGraph facts, RuleLang rules, impact reports, agent-safe tools, and hash-only preview calendar credentials.

Parva Protocol is not an official government calendar publication and is not legal, tax, payroll, banking, or regulatory authority.
