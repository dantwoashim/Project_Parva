# PTS-013 Conformance

## Purpose

Conformance tests let an implementation prove compatibility with a protocol level.

## Levels

Levels include `parva_core`, `parva_source_aware`, `parva_trust`, `parva_timegraph`, `parva_rulelang`, `parva_impact`, `parva_agent_safe`, `parva_offline`, and `parva_full`.

## Reports

Reports must include implementation name, protocol version, level, status, counts, test results, warnings, and a report hash.
