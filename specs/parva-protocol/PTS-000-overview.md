# PTS-000 Overview

## Purpose

Parva Protocol defines public preview formats and conformance expectations for Nepali temporal infrastructure.

## Scope

The protocol covers date representation, source metadata, confidence labels, release manifests, trust logs, evidence packets, TimeGraph facts, RuleLang rules, impact reports, agent tools, credentials, conformance, offline bundles, and governance.

## Non-goals

The protocol does not claim government authority, legal authority, production cryptographic authority, or third-party certification.

## Conformance

Implementations must validate machine-readable schemas and pass the relevant conformance tests for any claimed compatibility level.
