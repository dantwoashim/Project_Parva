# Future BS Accuracy Policy

Project Parva's future-BS research layer is built for validation and risk detection, not for official publication authority.

Future outputs are treated as:

```text
computed_prediction_not_official
```

Accuracy claims must identify the source policy, evidence window, and corpus size used for validation.

Reproducibility requirements, public/private test lanes, and required metrics are
defined in [ACCURACY_REPRODUCIBILITY.md](ACCURACY_REPRODUCIBILITY.md).
