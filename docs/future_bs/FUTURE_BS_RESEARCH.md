# Future BS Research Layer

The Future BS subsystem studies unpublished BS month boundaries as an astronomical, civil-rule, and uncertainty problem. Its public result is a curated year forecast for `2084-2200 BS`, backed by a versioned snapshot and selected methodology artifact.

## Public Research Surface

- capability and forecast-range discovery
- selected model, calibration, and civil cutoff methodology
- one-year month-length forecasts
- month-level prediction sets and probabilities
- boundary-distance and risk labels
- sequence constraint checks
- validation scope and claim boundary

Public requests read a committed snapshot. This keeps responses deterministic, fast, reviewable, and reproducible from the same release.

## Research Architecture

```text
source-labeled month boundaries
  -> sidereal solar-ingress solver
  -> Nepal civil-time assignment
  -> month-specific cutoff candidates
  -> past-only statistical pattern stack
  -> constrained year-sequence decoder
  -> prediction sets and review labels
  -> curated public snapshot
```

The selected output always carries:

```text
publication_status = computed_prediction_not_official
review_required = true
authoritative_publication_overrides = true
```

## Controlled Research Surface

Raw model runs, broad ranges, exports, imports, residual analysis, external-sheet comparison, financial simulation, and private source material stay behind the research route profile. This division gives public users a useful forecast while protecting operational tools and unpublished evidence.

## Evidence Position

The official `2078-2083 BS` window produces a `72/72` calibrated replay. The engine states this as a fit result because calibration used the same official window. Broader independent validation remains pending and the public artifact records the 528-case evidence threshold.
