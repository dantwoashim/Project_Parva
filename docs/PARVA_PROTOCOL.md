# Parva Protocol

Parva Protocol is the public preview standard layer for programmable, verifiable, auditable Nepali time.

Version: `parva-protocol-0.1.0`

It defines specs, schemas, compatibility levels, conformance reports, hash-only preview credentials, registry layout, offline bundle format, and governance documents.

It does not claim government endorsement, legal authority, production signature authority, or third-party certification.
