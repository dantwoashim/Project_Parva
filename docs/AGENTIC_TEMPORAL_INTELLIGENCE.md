# Agentic Temporal Intelligence

The agent layer exposes deterministic Parva services as safe tools for humans, developers, and AI agents.

It is not a chatbot and does not let language text override engine truth.

Agent outputs include:

- result
- decision status
- reason codes
- confidence
- warnings
- evidence references
- human-review flag
- trace id

Unsupported claims return unsupported or review-required instead of fabricated certainty.
