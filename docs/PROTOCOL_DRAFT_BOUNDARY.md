# Protocol Draft Boundary

Status: Phase 04 protocol-draft boundary.

Parva Protocol is a draft interoperability layer for programmable, verifiable
Nepali time. It defines draft specs, schemas, conformance payloads, hash-only
preview credentials, registry layout, offline bundle shape, and governance
documents.

It is not a legal standard, government standard, W3C standard, certificate
authority, signature authority, or third-party certification program.

## Publicly Allowed

- protocol draft capabilities
- draft spec and schema indexes
- local conformance reports
- hash-only preview credentials
- offline bundle manifests
- draft governance metadata

## Required Labels

Protocol responses, docs, and SDK references must use draft language such as:

```text
maturity = protocol_draft
```

They must not use standard, certified, approved, or authority wording unless a
future phase adds real external governance and verification evidence.
