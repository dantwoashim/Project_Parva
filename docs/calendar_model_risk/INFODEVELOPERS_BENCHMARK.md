# InfoDevelopers Benchmark

The benchmark direction is an external-sheet challenger, not future lookup copying.

Process:

1. Import external Excel or CSV.
2. Normalize year/month rows.
3. Compare month-by-month against Parva computed predictions.
4. Classify disagreements by confidence, prediction set membership, boundary risk, and financial impact.
5. Keep all future Parva outputs marked `computed_prediction_not_official`.

The 2083 Ashwin replay is the flagship red-team case.
