# Calendar Model-Risk Overview

Parva is a complete Nepali calendar infrastructure platform extended with a Calendar Model-Risk Engine.

The model-risk layer answers:

- which future BS month length is predicted,
- how wide the prediction set is,
- which months are risky,
- where external sheets disagree,
- what the loan or contract exposure is,
- what no-break policy should be used before official publication.

All future predictions are `computed_prediction_not_official`.
