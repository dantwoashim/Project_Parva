# Protocol Credentials

Parva Calendar Credentials are hash-only preview credentials for portable temporal claims.

The public preview supports date-conversion credentials.

Credential verification checks schema shape, release id, source ids, reference conversion, and content hash.

Public credentials use `hash_only_preview`, not production signatures.
