# Frontend Maturity

The frontend in this repository is a public reference beta.

## What that means

- it is maintained, built, and tested
- it is suitable for demonstrating the canonical API platform
- it should not be marketed as a fully complete consumer product by default

## What is stable

- core read flows around today, festivals, personal place context, muhurta, and trust surfaces
- the shared shell and route structure
- integration with the canonical `/v3/api/*` platform

## What is not implied

- full account platform maturity
- cloud sync guarantees
- first-class member/product workflows beyond the current reference scope

## Productization rule

If the project later claims a full product posture, that should come with explicit scope, tests, and operational commitments rather than being inferred from the current reference app.
