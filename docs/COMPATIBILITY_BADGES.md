# Compatibility Badges

Public preview badge labels:

- Parva Compatible: Core
- Parva Compatible: Source-Aware
- Parva Compatible: Trust
- Parva Compatible: TimeGraph
- Parva Compatible: RuleLang
- Parva Compatible: Impact
- Parva Compatible: Agent-Safe
- Parva Compatible: Offline
- Parva Compatible: Full

A badge requires a conformance report, protocol version, level, implementation name, date, limitations, public/private mode, and report hash.

Project Parva Reference Implementation may claim only levels that pass local conformance.
