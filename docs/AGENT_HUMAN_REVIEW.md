# Agent Human Review Gates

Agent outputs require review when confidence is low, a fact is disputed, a claim is unsupported, a future or official claim lacks source support, or the use case is payroll, banking, legal, or fiscal sensitive.

The review flag is structured in `decision.requires_human_review`.
