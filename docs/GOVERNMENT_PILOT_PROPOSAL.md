# Machine-readable Nepali Calendar and Holiday Release Toolkit

This public-good pilot would help official institutions publish machine-readable
calendar and holiday release artifacts that software systems can verify.

Parva does not replace MoHA, NPNS, or any government authority. Official
institutions remain authoritative for their own publications. Parva can provide
open schemas, release manifests, hash verification, and integration tooling so
software systems consume official releases more reliably.

Pilot outputs:

- release JSON schema,
- source registry template,
- hash and transparency-log verification,
- sample holiday release bundle,
- public implementation guide,
- vendor conformance test fixture.
