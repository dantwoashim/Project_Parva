# Compatibility Reports

Compatibility reports are machine-readable JSON outputs generated by
`scripts/parva_conformance.py`.

## Format

Each report must include:

- `implementation`
- `protocol_version`
- `level`
- `status`
- `tests_run`, `passed`, and `failed`
- `test_results`
- `warnings`
- `limitations`
- `public_private_data_policy`
- `generated_at`
- `report_hash`

## Interpretation

A passing report means the local implementation passed the selected public
compatibility checks at the time of generation. It does not mean the
implementation is government approved, legally authoritative, externally
certified, or safe for unsupervised high-stakes decisions.

## Regeneration

Regenerate the full reference report with:

```bash
python scripts/parva_conformance.py --target local --level full --output reports/compatibility/project-parva-reference-full.json
```

If the runner, source registry, protocol schemas, release manifests, SDK files,
or compatibility criteria change, regenerate the report and rerun the public
verification gate before publishing the artifact.
