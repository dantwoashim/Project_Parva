# One-Page Government Brief

Submitted by: Prabin Ghimire

## Ask

Approve a pilot to encode one official Nepali calendar/Panchanga/holiday
release as a machine-readable digital release with source metadata, checksums,
API access, CSV/JSON files, offline bundle, and conformance tests.

## Core Line

Nepal does not need to replace Panchanga. Nepal needs to make Panchanga
machine-readable, source-backed, and verifiable for the digital era.

## What Parva Provides

- A reference implementation for release encoding.
- Public verification scripts.
- Source and confidence metadata.
- Review gates for institution-specific rules.
- Vendor conformance tests.

## What Parva Does Not Claim

- No government approval.
- No replacement of Panchanga authority.
- No legal, tax, banking, or payroll authority.
- No official future-date publication.
- No external certification.
