# National Digital Panchanga Pilot Proposal

Submitted by: Prabin Ghimire

Nepal does not need to replace Panchanga. Nepal needs to make Panchanga
machine-readable, source-backed, and verifiable for the digital era.

## Proposal

Approve a limited pilot to convert one official calendar, Panchanga, or holiday
release into a machine-readable, versioned, source-backed digital release with
API, CSV, JSON, offline bundle, and conformance tests.

Official bodies decide. Parva helps encode, verify, distribute, and test.

## Why This Matters

Government systems, schools, banks, cooperatives, payroll vendors, ERP vendors,
municipal services, and agent tools increasingly need reliable Nepali dates. Today,
many systems retype calendar data, scrape sources, or guess. That creates
avoidable errors in deadlines, holidays, payroll cutoffs, repayment reminders,
public notices, and service schedules.

The pilot creates a reference digital release format that preserves authority,
source evidence, checksums, versioning, and review boundaries.

## Pilot Deliverables

- One machine-readable calendar/Panchanga/holiday release.
- JSON, CSV, and offline bundle artifacts.
- Source metadata and authority boundary fields.
- Checksum file and verification script.
- API reference surface for read-only access.
- Vendor conformance tests for date handling.

## Boundary

Parva does not request authority to decide official dates. Parva requests
permission to demonstrate a reliable encoding and verification layer for dates
that official bodies already decide and publish.
