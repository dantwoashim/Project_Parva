# Machine-Readable Release Sample

A public-safe sample release lives in `samples/digital-panchanga-release/2083-bs`.

The sample is not official. It demonstrates structure:

- release metadata,
- holiday rows,
- festival rows,
- panchanga summary rows,
- source metadata,
- checksums,
- offline verification.

Do not use the sample as an official 2083 BS Panchanga or holiday publication.
