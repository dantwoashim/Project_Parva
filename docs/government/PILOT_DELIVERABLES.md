# Pilot Deliverables

Minimum pilot deliverables:

1. Select one official calendar, Panchanga, or holiday release.
2. Encode it as JSON, CSV, and offline bundle files.
3. Attach source metadata and authority boundary labels.
4. Publish checksums.
5. Run offline verification.
6. Provide a read-only API surface.
7. Provide vendor conformance tests.
8. Record limitations and review-required cases.

Success means the selected release can be consumed by software without manual
retyping and can be verified against checksums and source metadata.
