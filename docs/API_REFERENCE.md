# API Reference

The current stable public API reference is [API Reference v3](API_REFERENCE_V3.md).

Version policy:

- `v3` is stable/core and is the SDK default.
- `v4` is public preview or metadata-only capability surface.
- `v5` is model-risk/research or explicit preview.
- `v2` is deprecated compatibility.

See [API Versioning and Deprecation](API_VERSIONING_AND_DEPRECATION.md).
