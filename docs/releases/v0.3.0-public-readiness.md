# v0.3.0 Public Readiness

Project Parva v0.3.0 is a public-beta readiness release focused on
reproducible verification, developer adoption, public-safe benchmark evidence,
package distribution readiness, optional Agent/MCP adapters, and explicit
authority boundaries.

## Included

- Public verification workflow for GitHub Actions.
- Clean-clone assumptions checker.
- Public claims checker for unsupported authority/adoption language.
- Nepali Time Reliability Benchmark v0 with 64 public-safe tasks.
- Generated benchmark badge, summary JSON, and `/benchmark` frontend surface.
- Machine-readable benchmark schema, runners, comparison output, and tests.
- Python and JavaScript SDK public-safe tests, package metadata, and dry-run
  publishing guidance.
- Safety-bound LangChain/LlamaIndex descriptors and example.
- Optional read-only MCP manifest, registry metadata, CLI checks, and registry
  submission notes.
- Optional JPL/ephemeris kernel verification and differential report.
- External temporal rule registry validator and sample institution profiles.
- Government and vendor packets framed as proposals and audit offerings only.
- Distribution-readiness packet for public-beta launch review.

## Current Evidence

- Benchmark Parva score: 87.19% across 64 tasks.
- Static baseline score: 19.38% across the same tasks.
- Future-BS capability surfaces expose `computed_prediction_not_official` and
  `review_required: true`.
- JPL kernels are optional for public runtime; when present locally, hashes are
  verified before use.
- Public benchmark results and reproducible verification commands provide the
  release evidence for this version.

## Safe Claims

- Parva is source-backed Nepali temporal infrastructure.
- Parva exposes public-safe APIs for supported BS/AD conversion, fiscal logic,
  festival metadata, panchanga summaries, trust metadata, and review gates.
- Parva includes a reproducible public benchmark and verification workflow.
- Parva package metadata is prepared for public-beta registry publication.
- Agent and MCP integrations are optional read-only adapters over public-safe
  routes.

## Not Claimable

- No government authority.
- No legal, tax, payroll, or banking authority.
- No official future date authority.
- No external certification.
- No customer, vendor, or government adoption proof.
- No public exact unsupported Future-BS predictions.
- No PyPI/npm publication unless registry entries exist.
- No MCP registry acceptance unless a merged registry entry exists.
